AURASOFT / AURABEAUTY — sitio web académico

PARA VER LA PÁGINA:
1. Descarga el archivo ZIP y descomprímelo/extrae su contenido.
2. Abre la carpeta aurasoft_aurabeauty_updated.
3. Haz doble clic en index.html y ábrelo con Chrome, Edge o Firefox.
4. Mantén la carpeta imagenes junto al archivo index.html; no muevas las imágenes fuera de ella.

CONTENIDO:
- index.html: contenido del sitio.
- style.css: estilos adaptables a celular y computador.
- script.js: menú móvil, interacciones y formulario que prepara un correo.
- imagenes/: logo, foto de trabajo de campo e imágenes de referencia visual para productos y servicios.

IMPORTANTE:
Las imágenes de productos/IA son referencias decorativas. No significan que esas funciones estén ya implementadas en AURABEAUTY. El formulario no envía ni almacena datos por sí solo: prepara un correo para que la persona lo revise y lo envíe.
